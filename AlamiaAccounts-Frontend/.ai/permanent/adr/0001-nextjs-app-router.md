# ADR-0001: Next.js 14 App Router Architecture

## Status
Accepted

## Date
2026-02-15

## Context
A modern, responsive, component-driven user interface was needed for Alamia Accounts, capable of being deployed as a standalone Node app or exported statically to Laravel public directory.

## Decision
We adopted Next.js 14 App Router with React, Tailwind CSS, and Shadcn UI.
