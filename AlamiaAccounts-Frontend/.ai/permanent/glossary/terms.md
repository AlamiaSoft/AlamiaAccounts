# Frontend Glossary: UI & Domain Terms

* **`VoucherEntry`**: Form component allowing users to construct balanced multi-line debit/credit journal vouchers.
* **`AccountTreeView`**: Interactive collapsible tree visualizer for parent/child chart of accounts hierarchy.
* **`Daybook`**: Daily ledger log showing journal transactions recorded for a given date.
* **`Cashbook`**: Specialized filter of the daybook focused strictly on cash and bank ledger accounts.
* **`CompanySwitcher`**: UI dropdown triggering domain context switch API calls.
* **`React Query QueryClient`**: Central cache managing API response invalidation and synchronization.
